# Ansible Básico

Prácticas y playbooks básicos de Ansible.

## Estructura

- `infra/`: Archivos de configuración de infraestructura (Terraform / Cloud).
- `01-ping.yml`: Comprobación de conectividad.
- `02-instalar-paquete.yml`: Instalación de paquetes.
- `03-crear-archivo.yml`: Creación y copia de archivos.
- `04-variables.yml`: Manejo de variables.
- `05-nginx.yml`: Instalación y servicio de Nginx.
- `06-template.yml`: Uso de plantillas Jinja2 (`pagina.html.j2`).
- `ansible.cfg`: Configuración local de Ansible.
- `inventario.ini`: Inventario de hosts.
- `pagina.html.j2`: Plantilla HTML de ejemplo.
